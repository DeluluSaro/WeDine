# WeDine RFID System - Hardware Shopping List

## 🛒 Complete Shopping Guide

### Essential Components (Required)

#### 1. ESP8266 Development Board
**Recommended: NodeMCU v1.0**
- **Price**: $3-5 USD
- **Where to buy**: Amazon, AliExpress, local electronics store
- **Alternative**: Wemos D1 Mini ($2-4)
- **Features**: Built-in WiFi, USB programming, 3.3V/5V compatible

#### 2. RC522 RFID Module
**13.56MHz RFID Reader/Writer**
- **Price**: $2-4 USD
- **Where to buy**: Amazon, AliExpress, local electronics store
- **Includes**: Reader module, antenna, jumper wires
- **Compatibility**: MIFARE Classic, NTAG, ISO14443A

#### 3. RFID Cards/Tags
**MIFARE Classic 1K Cards (Recommended)**
- **Price**: $0.50-1 USD per card
- **Quantity**: 10-20 cards for testing
- **Where to buy**: Amazon, AliExpress, local electronics store
- **Alternative**: Use existing college ID cards (if compatible)

#### 4. Jumper Wires
**Male-to-Male Jumper Wires**
- **Price**: $2-3 USD
- **Quantity**: 7 pieces minimum
- **Length**: 20cm (8 inches) recommended
- **Color**: Different colors for easy identification

#### 5. Breadboard (Optional but Recommended)
**Half-size Breadboard**
- **Price**: $3-5 USD
- **Size**: 400 points (half-size)
- **Purpose**: Easy prototyping and testing
- **Alternative**: Direct wiring (more permanent)

#### 6. LED (Optional)
**5mm LED for Visual Feedback**
- **Price**: $0.50-1 USD
- **Color**: Any color (red, green, blue)
- **Resistor**: 220Ω resistor (included in LED kits)
- **Purpose**: Visual confirmation of card detection

### Power Supply Options

#### Option 1: USB Power (Recommended)
- **USB Cable**: Micro-USB cable ($2-3)
- **Power Adapter**: 5V 2A adapter ($3-5)
- **Advantages**: Easy to use, reliable
- **Disadvantages**: Requires wall outlet

#### Option 2: Battery Power
- **Battery Pack**: 5V USB power bank ($5-10)
- **Advantages**: Portable, no wall outlet needed
- **Disadvantages**: Needs recharging

#### Option 3: Direct Power
- **Power Supply**: 5V 2A DC adapter ($3-5)
- **Connector**: Barrel jack to breadboard adapter ($2-3)
- **Advantages**: Permanent installation
- **Disadvantages**: Less portable

### Enclosure and Protection

#### 1. Project Box (Recommended)
**Plastic Project Enclosure**
- **Price**: $5-10 USD
- **Size**: 100x80x40mm (4x3x1.5 inches)
- **Material**: ABS plastic
- **Purpose**: Protect electronics from dust and damage

#### 2. Mounting Hardware
**Screws and Standoffs**
- **Price**: $2-3 USD
- **Quantity**: 4 screws, 4 standoffs
- **Size**: M3 screws and standoffs
- **Purpose**: Secure mounting

### Tools Required

#### 1. Soldering Iron (Optional)
**Basic Soldering Kit**
- **Price**: $10-20 USD
- **Purpose**: Permanent connections
- **Alternative**: Use breadboard (no soldering needed)

#### 2. Multimeter (Optional)
**Digital Multimeter**
- **Price**: $10-20 USD
- **Purpose**: Troubleshooting and testing
- **Alternative**: Not required for basic setup

#### 3. Wire Strippers (Optional)
**Basic Wire Strippers**
- **Price**: $5-10 USD
- **Purpose**: Preparing wires
- **Alternative**: Use pre-made jumper wires

## 🔍 Product Recommendations

### ESP8266 Boards

#### 1. NodeMCU v1.0 (Recommended)
- **Model**: ESP-12E based
- **Price**: $4-5
- **Features**: Built-in USB, 3.3V/5V compatible
- **Pros**: Easy to use, well-documented
- **Cons**: Slightly larger

#### 2. Wemos D1 Mini
- **Model**: ESP-12F based
- **Price**: $2-3
- **Features**: Compact, breadboard-friendly
- **Pros**: Small, cheap, good for projects
- **Cons**: No built-in USB (need adapter)

#### 3. ESP8266-01
- **Model**: Minimal ESP8266
- **Price**: $1-2
- **Features**: Very small, basic functionality
- **Pros**: Very cheap, tiny
- **Cons**: Limited pins, harder to program

### RFID Modules

#### 1. RC522 (Recommended)
- **Price**: $2-4
- **Features**: 13.56MHz, MIFARE compatible
- **Pros**: Popular, well-supported, cheap
- **Cons**: Basic functionality

#### 2. PN532
- **Price**: $5-8
- **Features**: More advanced, better range
- **Pros**: Better performance, more features
- **Cons**: More expensive, complex

#### 3. MFRC522 Breakout
- **Price**: $3-5
- **Features**: Pre-soldered, easy to use
- **Pros**: Ready to use, good documentation
- **Cons**: Slightly more expensive

## ⚠️ Important Notes

### Compatibility
- **Ensure 3.3V compatibility** - ESP8266 runs on 3.3V
- **Check pin compatibility** - Verify GPIO pin assignments
- **Test before buying** - Some components may not work together

### Quality Considerations
- **Buy from reputable sellers** - Check reviews and ratings
- **Avoid extremely cheap components** - May be counterfeit
- **Test components** - Verify functionality before final assembly

### Shipping Considerations
- **Order early** - Some components take weeks to arrive
- **Buy extras** - Components can be damaged during shipping
- **Check return policy** - In case of defective components
